# Sicherheit

Sicherheitslücken bitte nicht öffentlich als Issue melden, sondern per E-Mail an arthurtschik.business@gmail.com.

Echte Versionen erkennst du daran, dass sie nur aus den [Releases](../../releases) dieses Repositories stammen und dort eine Prüfsumme (`Ferienrechner.apk.sha256`) mitgeliefert wird. Android akzeptiert Updates außerdem nur, wenn sie mit demselben Schlüssel signiert sind wie die installierte App.
